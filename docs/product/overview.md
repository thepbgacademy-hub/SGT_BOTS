# Product Overview

SGT_BOTS is a Telegram mini app playground that lets users join a Telegram group, create a profile, connect their own LLM provider account, and test multiple specialized bots inside a shared premium UI.

The product exists to demonstrate differentiated bot capabilities, collect qualified user interest, and convert engaged users into a paid community.

The canonical product design lives in `../superpowers/specs/2026-05-05-telegram-playground-design.md`.
